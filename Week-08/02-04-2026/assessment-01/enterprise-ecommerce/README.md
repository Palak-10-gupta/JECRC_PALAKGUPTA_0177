# 🚀 NexaShop – Enterprise E-commerce Platform

NexaShop is a modern, enterprise-level e-commerce web application built using **React.js**. It features a clean UI, role-based dashboard, product management, analytics, and authentication flows — all designed with a **premium pastel UI**.

---

## 🌟 Features

### 🔹 Public Pages

* 🏠 Home page with hero section & features
* ℹ️ About page with company info & team
* 📞 Contact page with form submission
* 🛍️ Product listing with search & filters
* 📦 Product detail page with:

  * Reviews
  * Specifications

---

### 🔐 Authentication

* Login & Register system
* Context-based authentication (AuthContext)
* Protected routes for dashboard access

---

### 📊 Dashboard (Protected)

* 📈 Analytics with charts & revenue data
* 📦 Product overview
* ⚙️ Settings page (profile + preferences)
* 🧾 Recent orders table
* 🎯 Stats cards (Revenue, Orders, Products)

---

### 🎨 UI/UX Highlights

* 🌈 Bright pastel color theme
* 💎 Clean & modern SaaS design
* 📱 Fully responsive layout
* 🧊 Glass-like cards & soft shadows
* ✨ Smooth hover effects

---

## 🛠️ Tech Stack

* ⚛️ React.js
* 🔀 React Router DOM
* 🎨 CSS (Custom styling with variables)
* 🧠 Context API (Authentication)
* 📦 Functional Components + Hooks
