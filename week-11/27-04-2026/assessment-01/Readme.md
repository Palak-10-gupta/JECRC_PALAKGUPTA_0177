# Basic Coding Problems README

## 1. Sum of Digits Problem

### Problem Statement
Write a function to calculate the sum of digits of a given number.

### Input
An integer n

### Output
The sum of digits of n

### Example
Input:
12345

Output:
15

---

## 2. Palindrome Problem

### Problem Statement
Check if a given string is a palindrome.

### Input
A string s

### Output
True if palindrome otherwise False

### Example
Input:
racecar

Output:
True

---

## 3. FizzBuzz Problem

### Problem Statement
Print numbers from 1 to n.

For multiples of 3 print Fizz  
For multiples of 5 print Buzz  
For multiples of both print FizzBuzz

### Input
An integer n

### Output
Numbers from 1 to n with replacements

### Example
Input:
15

Output:
1  
2  
Fizz  
4  
Buzz  
Fizz  
7  
8  
Fizz  
Buzz  
11  
Fizz  
13  
14  
FizzBuzz

---

## 4. Two Sum Problem

### Problem Statement
Given an array and target, return indices of two numbers whose sum equals target.

### Input
Array nums  
Target integer

### Output
Indices of required numbers

### Example
Input:
nums = [2,7,11,15]  
target = 9

Output:
[0,1]


---

## 5. Find Missing Number Problem

### Problem Statement
Given an array of n-1 numbers from 1 to n, find the missing number.

### Input
Integer array

### Output
Missing number

### Example
Input:
1 2 4 6 3 7 8

Output:
5

---

## 6. Merge Sorted Arrays Problem

### Problem Statement
Merge two sorted arrays into a single sorted array.

### Input
Two sorted arrays

### Output
Merged sorted array

### Example
Input:
1 3 5  
2 4 6

Output:
1 2 3 4 5 6
