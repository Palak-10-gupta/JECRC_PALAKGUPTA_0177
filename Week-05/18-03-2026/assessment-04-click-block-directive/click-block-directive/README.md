# 🚫 Click Block Directive – Angular Custom Directive

This project prevents user interaction dynamically based on a condition.

---

## 🚀 Logic

* Condition = false → Click Blocked
* Condition = true → Click Allowed

---

## 🛠️ Project Creation Commands

```bash
ng new click-block-directive
cd click-block-directive

ng generate directive clickBlock --standalone
ng generate component action-panel --standalone
```

---

## 🎯 Features

* Enable / Disable Access toggle
* Prevent click using HostListener
* Action feedback alerts
* Disabled UI state styling
* Feature dashboard layout

---

## ▶️ Run Project

```bash
ng serve
```
