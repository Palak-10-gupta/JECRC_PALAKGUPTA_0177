# 🔐 Role Based Directive – Angular Custom Directive

This project implements a **custom directive** to restrict UI visibility based on user role.

---

## 🚀 Logic

* Admin → All sections visible
* Student → Only limited sections visible

---

## 🛠️ Project Creation Commands

```bash
ng new role-based-directive
cd role-based-directive

ng generate directive roleBased --standalone
ng generate component portal --standalone
```

---

## 🎯 Features

* Admin / Student login toggle
* Dynamic feature visibility
* Role based UI rendering
* Modern card dashboard layout
* Responsive design

---

## ▶️ Run Project

```bash
ng serve
```
