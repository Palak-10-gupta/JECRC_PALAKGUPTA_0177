# 💰 Price Highlight Directive – Angular Custom Directive

This project highlights products dynamically based on price value.

---

## 🚀 Logic

* Price > 50000 → High Value → Red Highlight
* Price ≤ 50000 → Normal → Green Highlight

---

## 🛠️ Project Creation Commands

```bash
ng new price-highlight-directive
cd price-highlight-directive

ng generate directive priceHighlight --standalone
ng generate component product-dashboard --standalone
```

---

## 🎯 Features

* Product card dashboard
* Visual price categorization
* Status badges
* Clean UI with shadows
* Responsive grid layout

---

## ▶️ Run Project

```bash
ng serve
```
