# 🎓 Student Dashboard – Angular Built-in Directives

This project demonstrates the usage of **Angular Structural and Attribute Directives** to create a dynamic student dashboard.

---

## 🚀 Angular Concepts Used

* *ngFor → List students
* *ngIf → Show Pass / Fail
* ngSwitch → Display Grade
* ngClass → Highlight toppers
* ngStyle → Color result status

---

## 🛠️ Project Creation Commands

```bash
ng new student-dashboard
cd student-dashboard

ng generate component dashboard --standalone
```

---

## 🎯 Features

* Dynamic student listing
* Automatic grade calculation
* Pass / Fail visualization
* Topper highlighting
* Clean table UI layout
* Responsive design

---

## ▶️ Run Project

```bash
ng serve
```

Open: http://localhost:4200
