# 🎨 Theme Directive – Angular Custom Directive

This project implements **dynamic theme switching** using a custom directive.

---

## 🚀 Logic

* Dark Mode → Dark background + Light text
* Light Mode → Light background + Dark text

---

## 🛠️ Project Creation Commands

```bash
ng new theme-directive
cd theme-directive

ng generate directive theme --standalone
ng generate component theme-dashboard --standalone
```

---

## 🎯 Features

* Dark / Light theme toggle
* Smooth transition effect
* Directive-based theme application
* Card dashboard layout
* Modern UI design

---

## ▶️ Run Project

```bash
ng serve
```
