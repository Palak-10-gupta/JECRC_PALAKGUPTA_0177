# 🌗 Toggle Theme App (Light/Dark Mode)

A simple and modern React application that allows users to switch between **Light Mode ☀️** and **Dark Mode 🌙** with a smooth and premium UI experience.

---

## 🚀 Features

* 🌗 Toggle between Light and Dark themes
* 🎨 Dynamic background and text color changes
* 🔘 Interactive button with smooth hover effects
* 📱 Responsive and centered UI
* ✨ Premium glassmorphism design
* ⚡ Smooth transitions

---

## 🧠 Concepts Used

* React **useState Hook**
* Boolean State Management
* Conditional Styling
* Ternary Operator
* Event Handling

---

## 🛠️ Tech Stack

* React.js
* CSS3 (Modern UI styling)

---

## 🎯 How It Works

* The app uses a **boolean state (`darkMode`)**
* When the button is clicked:

  * `false → true` (Light → Dark)
  * `true → false` (Dark → Light)
* UI updates using **conditional class names**
* Text and button label change using a **ternary operator**
