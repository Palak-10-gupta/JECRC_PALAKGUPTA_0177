# 📝 Todo List App (React)

A simple and modern Todo List application built using React that allows users to manage daily tasks efficiently.

---

## 🚀 Features

* ➕ Add new tasks
* ❌ Delete tasks
* ☑ Mark tasks as completed
* 🎨 Clean and premium UI
* ⚡ Real-time updates

---

## 🧠 Concepts Used

* React **useState Hook**
* Array State Management
* **map()** for rendering list
* **filter()** for deleting tasks
* Immutable state updates

---

## 🛠️ Tech Stack

* React.js
* CSS3

## 🎯 How It Works

* Tasks are stored in an **array state**
* Each task has:

  * id
  * text
  * completed status
* Clicking on a task toggles completion
* Delete button removes task using **filter()**
* UI updates dynamically using **map()**
